# <a name="aggregate"></a>Aggregation of single-cell singals into metacells
Using the metacell assignments generated by scDART and SEACells, we aggregated single-cell gene expression, CRE ATAC signal and CRE TSS signal into metacells. Raw counts from individual cells were summed within each metacell to generate metacell-level profiles for all three modalities. These matrices were integrated into a Seurat object containing RNA, aCRE and tCRE assays. Metacells containing fewer than three RNA-profiled cells or three ATAC-profiled cells were excluded, retaining 393 metacells for downstream analyses. Each assay was independently normalized using Seurat's LogNormalize method with a scale factor of 10,000.
For metacell-level transcriptomic characterization, highly variable genes were identified from the normalized RNA data, followed by scaling, principal component analysis (PCA) and UMAP using the first 30 principal components. Graph-based clustering was performed using Louvain and Leiden algorithms, and cell-cycle phases were assigned using Seurat's CellCycleScoring function. Metacell pseudotime was calculated as the mean pseudotime of constituent RNA-profiled cells. For visualization, metacell coordinates were obtained by averaging the corresponding single-cell UMAP coordinates within each metacell.


# <a name="curation"></a>Manual curation of TF function
TF motifs from the JASPAR 2024 CORE vertebrate non-redundant collection were mapped to corresponding TF genes. For motifs associated with multiple TFs, individual TF names were separated and standardized to approved HGNC gene symbols using the HGNC Symbol Checker. TF functional annotations were retrieved from UniProt using ID mapping, retaining reviewed entries with available functional descriptions. TFs were manually curated as pioneer, transcriptional activators, repressors or unknown based on UniProt functional descriptions and literature-supported annotations. Multiple annotations were allowed for each TF. We assigned “unknown” to those TFs without annotation while these TFs were not included in enrichment tests.
To restrict motif analyses to TFs expressed during neural differentiation, TF expression was quantified across metacells using log-normalized sc5nRNA-seq expression values. Motifs were retained when the corresponding TF reached an expression value of at least 0.2 in three or more metacells. For motifs corresponding to a single TF, this criterion was applied to that TF directly. For composite motifs representing two TFs, both corresponding TFs were required to satisfy the expression threshold in the same metacells. This filtering retained 420 expressed TF motifs for downstream motif-activity analyses. The resulting TF–motif annotations, expression summaries and curated functional classifications were used for downstream ChromVar and TF regulatory-mode analyses.
